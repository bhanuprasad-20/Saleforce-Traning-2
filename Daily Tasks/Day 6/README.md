# Chapter 6 – Making Software Respond Automatically

## Salesforce Developer Training

### About This Chapter

In this chapter, I learned how Salesforce can automatically respond when something important happens in the system. I mainly worked with **Apex Triggers** and learned how they can be used to handle business events.

I used the **Placement Management System** as the example for understanding these concepts.

### What I Learned

- What Apex Triggers are
- How Triggers respond to changes in records
- What event-driven programming means
- How to identify important business events
- How to design a Trigger properly
- Why business logic should be separated from the Trigger
- How service classes can be used with Triggers
