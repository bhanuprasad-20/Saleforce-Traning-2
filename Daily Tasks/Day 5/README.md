# Day 05 – Salesforce Developer Training

## Apex Business Logic

Today, I learned how Apex can be used to handle business rules in the Placement Management System.

## Application Service

I worked with an `ApplicationService` class to keep the application-related logic in one place.

This makes the code easier to understand, reuse, and maintain.

## Application Process

I worked on the `submitApplication()` process, which follows these steps:

* Receive the application.
* Check for duplicate applications.
* Check student eligibility.
* Save the application.
* Show a clear result.

## Validation

I learned how to check important rules such as:

* Duplicate applications.
* Minimum CGPA requirements.
* Student eligibility.
* Company requirements.

## Code Quality

I also learned the importance of:

* Keeping methods simple and focused.
* Using meaningful names.
* Avoiding SOQL inside loops.
* Separating different responsibilities.

Day 05 helped me understand how to **turn business requirements into clean and reusable Apex code** and why good code should be easy to understand and maintain.
