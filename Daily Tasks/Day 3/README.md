# Day 03 – Salesforce Developer Training

## Validation Rules

Today, I learned how Validation Rules help check whether the data entered by a user is correct before saving a record.

I practiced validations for:

* Student CGPA
* Application Date
* Mandatory fields

## Record-Triggered Flow

I worked on a Record-Triggered Flow for the Placement Management System.

The flow was used to:

* Set the Application Date automatically.
* Send an email notification.
* Create an Offer Letter record.

## Trigger vs Flow

I learned when to use Flow and when to use an Apex Trigger.

* **Flow** – useful for simple automation.
* **Apex Trigger** – useful when more complex logic is required.

## Debugging

I also learned that having multiple automations can sometimes cause conflicts or repeated execution.

A better approach is to keep automation simple by using one Record-Triggered Flow and using Apex only when needed.


Day 03 helped me understand **Validation Rules, Record-Triggered Flows, automation, and when to use Flow or Apex Trigger**.
