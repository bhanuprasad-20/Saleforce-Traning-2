# Day 04 – Salesforce Developer Training

## Lightning Web Components

Today, I learned how the main parts of an LWC work together.

* **HTML** – used to design the page and display information.
* **JavaScript** – used for logic, variables, and user actions.
* **Meta XML** – used to make the component available in Lightning App Builder.

## Hands-on Practice

I created a `placementHome` component that displays:

**Welcome to Vishnu Placement Portal**

I also practiced JavaScript variables and button clicks to make the component interactive.

## Data Binding

I learned how changes in JavaScript can automatically update the values displayed in HTML.

## Placement Portal

I created a simple Placement Portal home page using LWC. It displays:

* Today's date
* Number of companies
* Number of jobs
* Applications submitted

## What I Learned

Day 04 helped me understand **LWC structure, JavaScript, button events, data binding, and building a simple Placement Portal**.
